# Introduction

**Compliance Store** is an open source project exploring how to store and manage documents in a regulatory compliance context, with an architecture designed to stay testable, decoupled, and easy to evolve.

This site is not the exhaustive technical documentation of the repository (that lives in `docs/` at the root of the code, alongside the ADRs). It's more of a communication space:

- **documentation pages** that give an accessible overview of the project and its architectural choices;
- a **changelog** (the blog) that tells the story of refactors, technical decisions, and key moments in the project, as they happen.
